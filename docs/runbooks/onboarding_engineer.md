# Engineering Onboarding Runbook

## Week 1 goals

1. Build workspace locally.
2. Read architecture map and ownership matrix.
3. Submit first PR in owned crate.

## Checklist

1. Install toolchain from rust-toolchain.toml.
2. Run full local validation commands.
3. Join team channels and review boards.
4. Read latest ADRs and relevant RFCs.
5. Pair with owner for first contribution.

## First PR expectations

1. Small scope.
2. Includes tests.
3. Includes docs update when interfaces change.
