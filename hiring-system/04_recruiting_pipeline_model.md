# Recruiting Pipeline Model

## Base conversion assumptions

| Stage transition | Baseline conversion |
|---|---:|
| Top-of-funnel to recruiter screen | 18% |
| Recruiter screen to technical stage | 40% |
| Technical stage to final stage | 35% |
| Final stage to offer | 45% |
| Offer to accept | 68% |

## Planning formula

Required funnel volume for N hires:

Top-of-funnel = N / (0.18 * 0.40 * 0.35 * 0.45 * 0.68)

Approximate multiplier: 144.3x hires.

Example:

- For 10 accepted hires, plan roughly 1,443 top-of-funnel contacts/applications.

## Weekly KPI targets

| KPI | Target |
|---|---|
| HM resume response SLA | 95% within 24h |
| Feedback SLA | 95% same day |
| Offer acceptance | 65% or higher |
| Candidate NPS | 50 or higher |
| P0 role time-to-fill | 75 days or less |

## Pipeline risk triggers

1. Technical pass rate below 20% for 2 consecutive weeks.
2. Offer acceptance below 55% in any month.
3. More than 20% interview feedback SLA misses.
4. P0 roles older than 60 days without finalist pipeline.

## Corrective actions

1. Recalibrate scorecard and interview loop.
2. Add executive outreach for close-risk finalists.
3. Shift recruiter capacity toward hard-role families.
4. Refresh compensation positioning for affected regions.
