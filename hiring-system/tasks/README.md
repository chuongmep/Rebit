# Rebit Task Assignment Packs

This folder contains one task TODO file per role in [../roles](../roles).
Each task file is structured for assignment, tracking, and weekly execution.

## How to use

1. Assign a person to `Assignee`.
2. Set target dates for each phase.
3. Update checkboxes weekly in hiring and engineering reviews.
4. Move blocked items to the weekly risk register.
