# Rebit Role Packs

This folder contains one markdown file per hiring row from the architecture role matrix.
Each file includes a full hiring packet:

- Job description and mission
- Phase-based scope of work (Months 1-2, 3-4, 5-6)
- Required experience and skill profile
- Compensation band and hiring regions
- Interview process and scorecard
- Sourcing strategy and screening questions
- 30/60/90-day outcomes
